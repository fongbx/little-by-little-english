# 慢慢学英语 · Little by Little English

A mobile-friendly English learning site for Mandarin speakers.

## What is included

- Everyday vocabulary grouped by scenes, with A1–C2 difficulty filters
- A 7,298-entry English–Chinese dictionary
- Ten practical phrases each day
- Local saved words and learning progress

The site is static. It does not require a server, login, or ChatGPT subscription. Saved words and progress stay in the current browser on the learner's device; they are not uploaded or synchronized.

## GitHub Pages

This repository is arranged to publish from the repository root with GitHub Actions. After creating the repository, choose **Settings → Pages → GitHub Actions**. Pushes to `main` then deploy the site. The URL will be:

`https://<your-github-username>.github.io/little-by-little-english/`

GitHub Pages is available on GitHub Free for public repositories. A public repository makes the app source and dictionary publicly viewable too. See [GitHub Pages documentation](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages).
